## 1. Testergebnis

- **Bestanden**
- Betroffenes Requirement: **TASTER_1_FUNCTION** (LED1 muss mit einer Umschaltzeit von 1000 ms blinken).

----------------------------------------------------

## 2. Interpretation

Der Test wurde bestanden, da die gemessenen Umschaltzeiten (1000 ms ± 0 ms) innerhalb der Toleranz von ±20 ms liegen. Die UART-Ausgabe zeigt regelmäßige „LED1 TOGGLE“-Nachrichten, die mit dem Timer-Interrupt übereinstimmen, der GPIOC ODR Bit 0 umschaltet, wenn der Taster PA11 gedrückt wird (Modus 1). Das SysML-Modell verknüpft TASTER_1_FUNCTION mit der LED1-Umschaltung, und der Traceability-Bericht bestätigt, dass die Anforderung implementiert ist. Alle Hinweise deuten auf eine korrekte Timer-/GPIO-Konfiguration und Tasterbehandlung hin.

----------------------------------------------------

## 2. Interpretation
Der UART‑Auszug gibt „LED1 TOGGLE …“ und einen Durchschnitt von 1000 ms an, was exakt die geforderte Umschaltzeit bedeutet. Im Code wird TIM2 mit PSC = 84000‑1 und ARR = 1000‑1 konfiguriert; dieser Timer erzeugt ein Update‑Event (SR‑Bit = 1) in einem Intervall von 1 s, das im While‑Loop abgefragt und zur LED‑Umschaltung verwendet wird. Damit ist das Requirement T1_TIMING erfüllt – das gemessene Intervall entspricht der Sollwert‑Vorstellung, es gibt keinen Widerspruch zwischen Messwert und Anforderung.
